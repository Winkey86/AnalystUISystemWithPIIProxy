# Правила работы с агентами и data tools

- Не переключаться в `main` или `master` без явной команды пользователя.
- Не коммитить и не пушить изменения в `main` или `master`.
- Не пушить изменения без отдельной явной команды пользователя.
- Не переписывать существующие сервисы без необходимости; новые возможности добавлять модульно.
- `services/data-tools` является deterministic data tools layer для загрузки датасетов, инспекции, профилирования и read-only SQL.
- `services/data-tools` не является LLM-агентом.
- Не отправлять датасеты целиком или их большие фрагменты в LLM.
- Не реализовывать arbitrary Python executor.
- SQL-инструменты должны выполнять только read-only `SELECT` / `WITH ... SELECT`.
- Все новые behavior должны быть покрыты тестами.
